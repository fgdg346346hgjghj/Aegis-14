Как работать с разбором

1. Сначала попробуй сам
На ключевых шагах есть поле «Проверь себя». Посчитай число на черновике и введи его, прежде чем листать дальше: попытка вспомнить запоминается лучше, чем чтение готового.
2. Один шаг — одно действие
Листай кнопками «Назад / Дальше» или стрелками ← →. Полоска сверху показывает, где ты; на любой шаг можно нажать. «Показать все шаги» раскрывает решение целиком.
3. Спрашивай «почему»
Под шагами есть раскрывающиеся блоки «Почему так?». Понятое правило легко восстановить на контрольной, а заученное путается.
4. Перепиши чистовик
Когда всё понятно, открой «Чистовик» и перепиши решение в тетрадь сам, сверяясь только в конце.

Систему из 4 уравнений решаем через X = A⁻¹·B: определитель, 16 алгебраических дополнений, транспонирование, умножение.

Условие

Коэффициенты при неизвестных переписываем в матрицу A: строка = уравнение, столбец = неизвестная. Неизвестные — в столбец X, правые части — в столбец B.

В третьем уравнении нет x3 — значит, на его месте пишем 0 (элемент a33 = 0). Пропустить ноль — самая частая причина неверного ответа.

Почему так?Умножь A на X по правилу «строка на столбец»: первая строка даёт 2x1 − x2 + 4x3 + 5x4 — ровно левую часть первого уравнения. Так все 4 уравнения превращаются в одно матричное A·X = B.
Откуда берётся X = A⁻¹·B
A · X = B
A⁻¹ · A · X = A⁻¹ · B  умножили обе части слева на A⁻¹
A⁻¹ · A = E  E — единичная матрица, E · X = X
X = A⁻¹ · B

Делить на матрицу нельзя, но можно умножить на обратную: A⁻¹·A = E, а E при умножении ничего не меняет — как единица у чисел.

Значит, план такой: найти A⁻¹, потом умножить её на B.

Шпаргалка к РГР

Три метода и одна теорема — всё, что нужно для этой работы.

Обратная матрица
  1. Записать A·X = B.
  2. Посчитать |A|; если |A| = 0 — метод не работает.
  3. Найти все Aij = (−1)i+j·Mij.
  4. A⁻¹ = 1/|A| · (Aij)ᵀ — дополнения строки i пишем в столбец i.
  5. X = A⁻¹·B (умножаем слева), проверить подстановкой.
Формулы Крамера
  1. Δ = |A| ≠ 0.
  2. Δk — в Δ k-й столбец заменить столбцом правых частей.
  3. xk = Δk / Δ.

Работает только для квадратной системы с Δ ≠ 0.

Метод Гаусса
  1. Расширенная матрица Ã.
  2. Прямой ход: строками сделать ступенчатый вид (поменять строки, умножить на число ≠ 0, прибавить другую строку с множителем).
  3. Сравнить ранги.
  4. Обратный ход: выразить неизвестные снизу вверх.
